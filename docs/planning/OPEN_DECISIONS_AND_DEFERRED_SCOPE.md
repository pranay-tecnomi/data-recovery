# Open Decisions and Deferred Scope

## Decisions required before production
- Exact supported macOS versions.
- Distribution/signing/notarization strategy.
- Whether physical-device access is required in MVP.
- Raw image container policy.
- Retention/privacy policy for diagnostics.

## Deferred scope
APFS deleted-file recovery, HFS+ recovery, repair/write-back, distributed imaging, unrestricted parallel I/O.

These are explicitly excluded from MVP completion claims.
