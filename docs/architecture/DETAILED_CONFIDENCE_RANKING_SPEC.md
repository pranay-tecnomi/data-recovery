# Detailed Confidence Ranking Specification

Confidence is an explainable evidence aggregation, not a claim of certainty.

## Inputs
- metadata integrity
- chain consistency
- extent completeness
- allocation evidence
- file validation
- carving boundary evidence
- contradictory evidence

## Output
A bounded score plus categorical band and evidence list.

## Rules
No single cosmetic indicator may dominate structural corruption. Missing evidence reduces certainty but does not automatically reject useful candidates.

Scores must be reproducible for identical evidence and policy versions.
