# Project Glossary

Block device: byte-addressable storage source exposed as fixed logical blocks.
Carving: reconstructing files from raw data using signatures/structure.
Extent: contiguous logical range belonging to a file.
Filesystem metadata: structures describing files and allocation.
Image: stored copy of a storage source.
Quick scan: metadata-oriented scan.
Deep scan: raw and/or exhaustive analysis.
Source: media being analyzed.
Destination: separate location receiving recovered output.
TRIM: storage command that may make deleted SSD data unavailable for recovery.
