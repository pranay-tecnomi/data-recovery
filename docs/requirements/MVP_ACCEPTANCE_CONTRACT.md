# MVP Acceptance Contract

The MVP must: open supported external sources read-only; scan images; enumerate GPT/MBR; analyze supported FAT32/exFAT cases; carve and validate JPEG/PNG/PDF/ZIP; block source-as-destination; image with unreadable-range maps and safe resume; support cancellation; expose typed progress/errors; and pass corpus/fault-injection gates.

Excluded: guaranteed APFS deleted recovery, encryption bypass, physical repair and universal filesystem support.
