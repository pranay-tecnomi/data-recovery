# UI/UX Specification

## Primary screens
1. Welcome and safety guidance.
2. Source selection.
3. Device assessment.
4. Scan configuration.
5. Scan progress.
6. Results browser.
7. Preview.
8. Destination selection.
9. Recovery progress.
10. Completion and report.

## Information hierarchy
Show safety and recommended action first; technical details are progressively disclosed.

## Scan progress
Show current phase, bytes/regions processed, estimated information only when reliable, read-error warnings, pause/cancel controls.

## Results
Support search, type filters, confidence filters, sorting, preview, and clear origin labeling.

## Hard safety constraints
Recovery to source is blocked.
Repair is not mixed with recovery.
Uncertain results are labeled.
Active startup storage receives special guidance.

## Accessibility
Keyboard-first navigation, VoiceOver labels, scalable text, sufficient contrast, and status not conveyed by color alone.
